# Bashir Agro Database Schema Documentation

## 1. Overview
The database engine is **PostgreSQL**, designed with strict foreign key constraints, UTF-8 collation, soft deletes, and optimized B-Tree indexes for high-throughput operational tracking.

---

## 2. Core Entities & Relationships

### Users (`users`)
- `id` (bigint, PK)
- `name` (varchar 255)
- `email` (varchar 255, unique)
- `phone` (varchar 20, unique, nullable)
- `password` (varchar 255, hashed)
- `role` (varchar 30: `owner`, `admin`, `manager`, `supervisor`, `farmer`)
- `is_active` (boolean, default true)
- `last_login_at` (timestamp, nullable)
- `created_at`, `updated_at`

### Farmers (`farmers`)
- `id` (bigint, PK)
- `user_id` (bigint, FK -> `users.id`, nullable): Mobile app user account
- `farmer_code` (varchar 30, unique, e.g. `F-000001`)
- `full_name` (varchar 150)
- `phone` (varchar 20, unique)
- `nid` (varchar 30, nullable)
- `date_of_birth` (date, nullable)
- `gender` (varchar 20: পুরুষ, মহিলা, অন্যান্য)
- `address` (text)
- `primary_activity` (varchar 100)
- `experience_years` (integer, nullable)
- `profile_photo_path` (varchar 500, nullable)
- `app_access_enabled` (boolean, default true)
- `status` (varchar 30: `active`, `inactive`)
- `created_by` (bigint, FK -> `users.id`, nullable)
- `created_at`, `updated_at`, `deleted_at`

### Farm Locations (`farm_locations`)
- `id` (bigint, PK)
- `location_code` (varchar 30, unique, e.g. `LOC-000001`)
- `name` (varchar 150)
- `type` (varchar 50)
- `address` (text, nullable)
- `area` (decimal 10,2, nullable), `area_unit` (varchar 30)
- `latitude` (decimal 10,7, nullable)
- `longitude` (decimal 10,7, nullable)
- `geofence_radius_meters` (integer, default 20)
- `status` (varchar 30: `active`, `inactive`)
- `created_by` (bigint, FK -> `users.id`, nullable)
- `created_at`, `updated_at`, `deleted_at`

### Task Templates (`task_templates`)
- `id` (bigint, PK)
- `task_code` (varchar 30, unique, e.g. `TASK-000001`)
- `name` (varchar 150)
- `category` (varchar 50)
- `instructions` (text)
- `requires_evidence_photo` (boolean, default false)
- `min_photos_required` (integer, default 0)
- `requires_geofence_validation` (boolean, default true)
- `status` (varchar 30: `active`, `inactive`)
- `is_active` (boolean, default true)
- `created_by` (bigint, FK -> `users.id`, nullable)
- `created_at`, `updated_at`, `deleted_at`

### Task Assignments (`task_assignments`)
- `id` (bigint, PK)
- `task_template_id` (bigint, FK -> `task_templates.id`, cascade)
- `farmer_id` (bigint, FK -> `farmers.id`, cascade)
- `farm_location_id` (bigint, FK -> `farm_locations.id`, cascade)
- `scheduled_date` (date)
- `start_time` (time)
- `end_time` (time, nullable)
- `priority` (varchar 30: `normal`, `important`, `urgent`)
- `status` (varchar 30: `assigned`, `in_progress`, `completed`, `cancelled`, `late`)
- `notes` (text, nullable)
- `assigned_by` (bigint, FK -> `users.id`, nullable)
- `assigned_at` (timestamp)
- `started_at` (timestamp, nullable)
- `completed_at` (timestamp, nullable)
- `created_at`, `updated_at`, `deleted_at`

### Task Submissions (`task_submissions`)
- `id` (bigint, PK)
- `task_assignment_id` (bigint, FK -> `task_assignments.id`, unique)
- `farmer_notes` (text, nullable)
- `submission_latitude` (decimal 10,7, nullable)
- `submission_longitude` (decimal 10,7, nullable)
- `is_within_geofence` (boolean, default true)
- `submitted_at` (timestamp)
- `verified_by` (bigint, FK -> `users.id`, nullable)
- `verified_at` (timestamp, nullable)
- `verification_notes` (text, nullable)

### Evidence Photos (`evidence_photos`)
- `id` (bigint, PK)
- `task_submission_id` (bigint, FK -> `task_submissions.id`, cascade)
- `photo_path` (varchar 500)
- `caption` (varchar 255, nullable)
- `captured_at` (timestamp, nullable)
- `gps_latitude`, `gps_longitude` (decimal 10,7, nullable)

### Settings (`settings`)
- `id` (bigint, PK)
- `key` (varchar 150, unique)
- `value` (text, nullable)
- `type` (varchar 30)
- `group` (varchar 50)
- `description` (text, nullable)
- `is_editable` (boolean, default true)
- `created_by`, `updated_by` (bigint, FK -> `users.id`, nullable)

### Audit Logs (`audit_logs`)
- `id` (bigint, PK)
- `user_id` (bigint, FK -> `users.id`, nullable)
- `action` (varchar 100)
- `module` (varchar 50)
- `subject_type`, `subject_id` (polymorphic target)
- `description` (text, nullable)
- `old_values`, `new_values` (jsonb, nullable)
- `ip_address` (varchar 45, nullable)
- `user_agent` (text, nullable)
- `created_at` (timestamp)
